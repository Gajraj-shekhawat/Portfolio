One engineer, a whole coaching platform

Shikhar Classes runs JEE and NEET coaching. I built and run its complete software platform: the public website, online testing, admissions and payments, college predictors, a career-stream test and the API that connects them.

01 The challenge

The institute needed more than a brochure website: students had to register for scholarship tests and pay fees online, counsellors needed to track enquiries, and the website had to rank on Google for competitive-exam searches.

02 What I built

  • Main website with server-rendered blog and FAQ pages, an auto-generated sitemap and llms.txt so it ranks on Google and AI search.
  • An online JEE/NEET test platform (admin, student and API in one Next.js app) at test.shikharedtech.com.
  • An admissions CRM for enquiries, counsellors and follow-ups.
  • JoSAA IIT and NIT college predictors, scholarship registration and Xenon batch admissions with Razorpay fee payment.
  • StreamFit, an adaptive career-stream test for Class 10 with AI-read OMR answer sheets and PDF reports.
  • One Express + MongoDB + Redis API behind every app, with push-to-deploy for each repository.

03 Results

  • Live at shikharedtech.com and its sub-sites (test, admissions, JoSAA predictors, StreamFit)
  • Online registrations and fee payments instead of manual forms
  • SEO-ready content pages and AI-readable llms.txt
  • Every app deploys automatically on push
