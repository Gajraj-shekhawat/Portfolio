Why I Dropped Firebase and Sent Login Codes over WhatsApp

Shop owners in Jaipur kept missing SMS codes. So the codes now arrive on WhatsApp, and the whole login runs on our own backend.

The first version of the Neem Karoli Sales shop app used Firebase phone sign-in. It worked fine in testing. Then real shopkeepers started using it, and a surprising number of them never got the SMS. Some had DND turned on, some had full inboxes, some just had poor signal inside a godown.

Every missed code was a phone call to the depot asking "OTP nahi aaya". The whole point of the app was to reduce phone calls, so this had to change.

What we built instead

Login now runs entirely on our own Fastify backend. The app sends a phone number; the server creates a short-lived code, stores only a hash of it, and sends it on WhatsApp. When the user types it in, the server checks it, limits attempts, and returns a session. The app never sees anything except an opaque id for the login attempt.

I packaged this as a small shared phone-auth module, so both Android apps (the shop app and the depot staff app) use exactly the same flow.

Why WhatsApp works better here

  • Almost every shop owner already has WhatsApp open all day.
  • Messages arrive even when SMS is blocked by DND settings.
  • The code sits in a chat from a recognisable business, which feels more trustworthy than a random SMS sender.

Things I was careful about

  • Codes expire quickly and can only be tried a few times.
  • Rate limits per phone number and per device, so nobody can spam someone else's WhatsApp.
  • Hashing the code on the server, the same way you'd treat a password.
  • A fallback path, because no single channel is perfect.

Was it worth it?

Yes. The "OTP nahi aaya" calls stopped, we pay only for messages we send, and we're not locked into one provider for something as basic as login. If you're building for Indian small businesses, I'd seriously consider WhatsApp for codes. I wrote more about the options in OTP, passkeys or passwords.

The full project is in the Neem Karoli Sales case study.
