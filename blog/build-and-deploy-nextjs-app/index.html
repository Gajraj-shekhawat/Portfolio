Build and Deploy a Next.js App: From Zero to Live

Next.js gives you a fast website and a backend in one project. Here's how a Next.js app is created and put online, with two hosting options.

Next.js is a popular way to build websites and web apps with React. It handles pages, SEO, images and even simple backend endpoints in one project. Here's how a Next.js app goes from nothing to live.

Step 1: Create the app

With Node.js installed, run npx create-next-app@latest my-app and accept the recommended options (TypeScript, the App Router). Then cd my-app and npm run dev, and open http://localhost:3000.

Step 2: Add pages

In the App Router, each folder inside app becomes a page: app/about/page.tsx is /about. Set each page's title and description with the metadata export, which is great for SEO (full SEO checklist).

Step 3: Add a simple API

A file like app/api/contact/route.ts becomes an endpoint at /api/contact. It's handy for a contact form that saves enquiries or sends you an email. Validate the input on the server and keep secrets in environment variables.

Step 4a: Deploy on Vercel (simplest)

  1. Push the project to GitHub.
  2. Import the repository in Vercel and click deploy.
  3. Add your environment variables and your custom domain in the project settings.

Every push to GitHub then deploys automatically, with preview links for each change.

Step 4b: Deploy on your own server

On a DigitalOcean droplet, run npm ci, npm run build and npm start under PM2, with Nginx and a free SSL certificate in front, the same setup as in deploying a Node.js backend. This gives you more control and predictable costs for busy apps.

Which hosting should you pick?

  • Vercel: fastest to set up, great for marketing sites and most apps.
  • Your own server: more control, useful when you also run other services or need fixed monthly costs.
  • A static export on Cloudflare Pages: cheapest when the site has no server features (see how).
